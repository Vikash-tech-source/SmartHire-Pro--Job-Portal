SMART HIRE - MINI PROJECT
=========================
An interactive front-end prototype of an intelligent job discovery platform.

Features
--------
1. Dashboard with profile match and job recommendations
2. Search by job title, company or skill
3. Filters by location and job type
4. Sorting by relevance, latest and salary
5. Job detail modal with responsibilities, qualifications and benefits
6. Save/unsave jobs
7. Application tracker with statuses
8. Candidate profile and career preferences
9. Responsive UI for desktop/tablet/mobile

How to run
----------
Open index.html in Google Chrome or Microsoft Edge.
No server, database, or internet connection is required after the page loads.

Project concept
---------------
SmartHire reduces the effort of job discovery by combining job search, recommendation,
shortlisting and application tracking in one simple interface.

Suggested viva flow
-------------------
1. Open Dashboard and explain Smart Match.
2. Go to Find Jobs and search "JavaScript".
3. Filter by Dehradun / Internship.
4. Open IT Support Intern and explain details.
5. Save a job.
6. Apply and open Applications to show status tracking.
7. Open My Profile and explain profile-driven recommendations.
